Hướng dẫn thêm bài Listening

Bước 1. Chuẩn bị file âm thanh

Mỗi section một file .mp3, đặt tên không dấu, không khoảng trắng, ví dụ t1-s1.mp3, t1-s2.mp3.

Giới hạn quan trọng: tải file lên GitHub bằng trình duyệt chỉ nhận tối đa 25 MB mỗi file. Nén mỗi section xuống khoảng 3 đến 8 MB là đủ rõ để nghe.

Cách nén: dùng một trang nén mp3 trực tuyến (chọn chế độ mono, 64 kbps), hoặc nếu bạn có ffmpeg trên máy thì chạy:

ffmpeg -i goc.mp3 -ac 1 -b:a 64k t1-s1.mp3

Nên dùng âm thanh do bạn tự thu hoặc đã được cấp phép. Băng của sách Cambridge có bản quyền.

Bước 2. Tạo file đề .json

Đặt tên không dấu, ví dụ test1.json. Copy mẫu dưới đây rồi sửa. File đề không chứa đáp án (bạn giữ đáp án riêng để chữa bài).

{
 "title": "Listening Test 1",
 "type": "listening",
 "modes": ["practice", "exam"],
 "readSeconds": 30,
 "reviewSeconds": 120,
 "sections": [
  {
   "title": "Section 1",
   "audio": "audio/t1-s1.mp3",
   "transcript": "Nội dung bài nghe (không bắt buộc)",
   "groups": [
    {
     "type": "fill",
     "instruction": "Complete the notes. Write ONE WORD ONLY.",
     "items": [
      { "q": "Customer name: Mr ______" },
      { "q": "Phone number: 0412 ______" }
     ]
    },
    {
     "type": "mcq",
     "instruction": "Choose the correct letter.",
     "items": [
      { "q": "The caller wants to book", "o": ["a room", "a table", "a ticket"] }
     ]
    }
   ]
  }
 ]
}
  • type của nhóm câu: fill (điền từ, chỗ trống viết bằng ______) hoặc mcq (trắc nghiệm, các lựa chọn trong o).
  • Số câu tự đánh từ 1 đến hết theo thứ tự các section, nên Section 2 bắt đầu sau câu cuối của Section 1.
  • modes: bỏ bớt "practice" hoặc "exam" nếu muốn đề chỉ có một chế độ.
  • readSeconds: giây đọc trước mỗi section ở chế độ thi thật. reviewSeconds: giây chép đáp án cuối bài.

Bước 3. Đưa lên GitHub

  1. Vào kho GitHub, mở thư mục audio, bấm Add file → Upload files, kéo các file mp3 vào, bấm Commit changes.
  2. Mở thư mục listening, tải file test1.json lên tương tự.
  3. Vẫn trong listening, bấm vào index.json, bấm biểu tượng cây bút để sửa, thêm tên đề vào danh sách rồi Commit: 
    ["sample.json", "test1.json"]
  4. Đợi khoảng 1 phút, mở trang Listening và nhấn Ctrl + F5.

Bước 4. Kiểm tra trước khi giao

  • Vào chế độ Luyện tập nghe thử từng section, kiểm tra âm thanh khớp đúng section.
  • Vào Thi thật với một section ngắn để xem phần đọc trước và việc tự chuyển section.
  • Mở trang theo dõi, xem bài thử của bạn có hiện ở dòng Listening không.

Xóa đề

Bỏ tên đề khỏi listening/index.json. Muốn xóa hẳn thì xóa thêm file .json và các file mp3 tương ứng.
